# Boss Tracker (a Noita mod)

![preview](./workshop-preview.png)

An improved boss kill tracker.
Check the mod settings for a little bit of UI config.

This is an improved version of the 'boss kill message' by syagami that adds some UI elements as well as hopefully improves the boss kill detection (technical: we add the death callback via nxml instead of at runtime)

Install it from [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3729766626)
